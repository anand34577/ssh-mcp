# Artwork

| File | Use |
|---|---|
| `logo.svg`, `icon-256.png`, `icon-512.png` | App icon (the 256 px PNG is embedded in Windows builds) |
| `banner.svg` / `banner.png` | README header and anywhere a wide banner fits |
| `social-preview.png` (`.svg` source) | GitHub social preview (Settings > General > Social preview), link cards on X, LinkedIn, Slack, Discord |
| `social-square.png` (`.svg` source) | Square posts for LinkedIn, Instagram, Mastodon |
| `features.svg` | Feature overview |
| `how-it-works.svg` | Diagram of AI app, SSH MCP, and servers |
| `setup-demo.svg` | The setup in a terminal (generated by `tools/setup-demo.py`) |
| `chat-demo.svg` | Example conversation |

Brand colors: navy `#0B1220`, cyan `#22D3EE`, indigo `#6366F1`, violet `#A855F7`, green `#34D399`. The font is Inter, falling back to the system UI font.

After editing an SVG, regenerate the PNGs with headless Chrome or Chromium:

```bash
assets/tools/render.sh
```
